## 👋 Introduction

Hi, my name is Kyle! Welcome to my AWS re/Start Programme repository. This repo documents my journey through **AWS re/Start**, an AWS-backed, no-cost training program designed to prepare individuals for entry-level roles in cloud computing — regardless of prior technical background.

Over the course of the program, I'm building foundational skills across cloud concepts, Linux, networking, databases, security, and programming, while working toward the **AWS Certified Cloud Practitioner** certification.

This repository serves as a record of my labs, notes, certifications and badges, and projects completed throughout the course.

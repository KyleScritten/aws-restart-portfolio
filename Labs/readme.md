# 🧪 Labs

[← Back to the main portfolio](../README.md)

This directory documents the hands-on labs I completed during my AWS re/Start learning journey, which formed the core of the programme. Each lab was a chance to build, configure and troubleshoot real AWS resources rather than just read about them, and they cover everything from compute, storage and networking to security, databases, monitoring, automation and generative AI. The labs are grouped by topic area below, so you can jump straight to the skills you're most interested in.

| Folder Directory | Overview |
|---|---|
| [Cloud Architecture & Scaling](./Cloud%20Architecture%20%26%20Scaling/) | Covers cloud architecture principles, scalability, high availability, fault tolerance, and resilient AWS workloads. |
| [Compute Infrastructure](./Compute%20Infrastructure%20/) | Explores Amazon EC2, instance configuration, instance types, storage, and compute resource management. |
| [Databases & Data Services](./Databases%20%26%20Data%20Services/) | Introduces AWS database services, relational and non-relational databases, and data management concepts. |
| [DevOps & Automation](./DevOps%20%26%20Automation/) | Explores development tools, automation, scripting, and practices that support efficient software delivery and infrastructure management. |
| [Linux & Systems](./Linux%20%26%20Systems/) | Covers Linux commands, file management, system administration, Python programming, and process management. |
| [Machine Learning and Generative AI](./Machine%20Learning%20And%20Generative%20AI/) | Introduces artificial intelligence, machine learning concepts, and AWS AI services. |
| [Monitoring](./Monitoring/) | Explores monitoring, logging, troubleshooting, and visibility into AWS resources and workloads. |
| [Networking](./Networking/) | Covers Amazon VPC, subnets, route tables, gateways, network security, and connectivity concepts. |
| [Security](./Security/) | Explores AWS security principles, identity and access management, the Shared Responsibility Model, and security best practices. |
| [Serverless & Containers](./Serverless%20%26%20Containers/) | Introduces serverless computing, containerisation, and related AWS services and deployment concepts. |
| [Storage & Archiving](./Storage%20%26%20Archiving/) | Covers AWS storage services, storage types, lifecycle management, backup, and data archiving. |

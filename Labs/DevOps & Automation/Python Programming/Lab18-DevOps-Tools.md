# Evaluate a DevOps Tool : Jenkins VS AWS CodeDeploy

## Lab overview

The landscape for DevOps tools is continuously changing as new products and technology come to market. In this lab, I research a DevOps tool and identify use cases for it.

For the purpose of this lab, I have chosen to compare **Jenkins** and **AWS CodeDeploy** as DevOps tools.

## Question 1: What does each DevOps tool do?

### Jenkins

Jenkins is an open-source automation server used for Continuous Integration and Continuous Delivery (CI/CD). It builds code, runs automated tests, and deploys applications using pipelines that can be highly customized.

### AWS CodeDeploy

AWS CodeDeploy is a fully managed AWS deployment service that automates application deployments to EC2 instances, Lambda functions, and on-premises servers. It focuses specifically on deployment automation and release management.
